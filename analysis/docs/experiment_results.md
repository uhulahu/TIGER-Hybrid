# TIGER 实验结果汇总

所有实验基于 Beauty 数据集，测试集 22,363 样本。SID 为 4-token 序列：前三个 token 对应三层码本（每层 256 码字），第四个 token 用于处理碰撞——TIGER 原文使用随机分配的 Extra Token，我们的实验中尝试了学习第四层码本（L4）来替代，桶内使用匈牙利算法强制单射分配。如无特别说明，TIGER 训练仅使用 CE loss，碰撞处理使用 Extra Token。

> 在这里整理一下`model/logs/`下除了`model/logs/tiger.log`和`model/logs/tiger-0708.log`外的实验结果数据。以下的这些实验，都是在`rqvae/ckpt/Beauty/Jul-09-2026_02-06-03/last_epoch_model.pth`及以后的新tokenizer上做的，旧的因为没有控制变量/不够规范就暂时不整理具体数字了。

## 2. RQ-VAE 详细结果

### 2.1 配置说明

RQ-VAE 共有 3 层码本，每层 256 个码字。SID 为 `[L1, L2, L3, L4/Extra]`，第四个 token 处理碰撞。相关变体：

| 变体 | Train SK | Infer SK | 4th Token |
|------|:--:|:--:|------|
| TrainSK+InferSK (E1) | L3 | L3 | Extra |
| TrainSK+InferSK+Collab | L3 | L3 | Extra |
| TrainSK only (E2) | L3 | — | Extra |
| No SK (E3) | — | — | Extra |
| TrainSK+L4 | L3 | — | L4(λ=10) |
| No SK+L4 | — | — | L4(λ=10) |

### 2.2 E1: Baseline CE (TrainSK+InferSK)

| 阶段 | R@5 | R@10 | R@20 | N@5 | N@10 | N@20 | MRR@5 | MRR@10 | MRR@20 |
|------|------|------|------|------|------|------|------|------|------|
| Val | 0.0507 | 0.0772 | 0.1126 | 0.0335 | 0.0421 | 0.0510 | 0.0279 | 0.0314 | 0.0338 |
| Test | 0.0347 | 0.0564 | 0.0829 | 0.0228 | 0.0298 | 0.0365 | 0.0189 | 0.0217 | 0.0236 |

> Test 显著低于 Val（R@20 差距 0.0297）。Leave-one-out 构造下训练集比验证集短 1 步，验证集比测试集短 1 步，并且 Beauty 平均历史长度仅约 7.9。训练集 50.9% 样本 ≤3 步，长程依赖信号稀疏。用户兴趣可能在这每步+1 的间隙中已发生转移，而训练集缺乏足够的长序列来学习这种变化规律，从而在更长的验证/测试集上泛化能力不足。

### 2.3 Ablation: Sinkhorn 策略

| 实验 | Train SK | Infer SK | Test R@5 | Test R@10 | Test R@20 | Test N@20 |
|------|:--:|:--:|-----------|-----------|-----------|----------|
| E1 (TrainSK+InferSK) | L3 | L3 | 0.0347 | 0.0564 | 0.0829 | 0.0365 |
| E2 (TrainSK only) | L3 | — | **0.0353** | 0.0561 | 0.0826 | **0.0366** |
| E3 (No SK) | — | — | 0.0340 | 0.0540 | 0.0795 | 0.0347 |

> 导出时禁用 Sinkhorn + 用 Extra Token 兜底与训练时 Sinkhorn 效果持平（E2 ≈ E1）。完全不用 Sinkhorn（E3）则全面下降。

### 2.4 Ablation: Collaborative Regularization

| 实验 | Collab | Test R@5 | Test R@10 | Test R@20 | Test N@20 |
|------|:--:|-----------|-----------|-----------|----------|
| E1 | — | **0.0347** | **0.0564** | **0.0829** | **0.0365** |
| Collab | ✓ | 0.0342 | 0.0552 | 0.0820 | 0.0356 |

> 协同正则化未带来提升，所有指标略低于 baseline。

### 2.5 Ablation: First-Diff Pairwise Loss

| Variant | TIGER Loss | Test R@5 | Test R@10 | Test R@20 | Test N@20 |
|-----------|------------|-----------|-----------|-----------|----------|
| TrainSK+InferSK | CE | **0.0347** | **0.0564** | **0.0829** | **0.0365** |
| TrainSK+InferSK | CE + FD (w=0.1) | 0.0326 | 0.0524 | 0.0782 | 0.0346 |
| TrainSK+InferSK+Collab | CE | 0.0342 | 0.0552 | 0.0820 | 0.0356 |
| TrainSK+InferSK+Collab | CE + FD (w=0.1) | 0.0342 | 0.0541 | **0.0838** | 0.0361 |

> FD loss 在 RQ-VAE 上一致降低性能，on Collab tokenizer 上 R@20 微涨 0.0018 但 R@5/R@10 未改善。

### 2.6 Ablation: L4 替代 Extra Token (λ=10)

| SK | L4 | Test R@5 | Test R@10 | Test R@20 | Test N@20 |
|-----------|:--:|-----------|-----------|-----------|----------|
| TrainSK only | — | **0.0353** | **0.0561** | **0.0826** | **0.0366** |

| No SK | — | 0.0340 | 0.0540 | 0.0795 | 0.0347 |

## 3. RQ-KMeans 详细结果

RQ-KMeans 使用 K-Means 逐层训练 3 层码本（无 Sinkhorn，无 Collab），TIGER 训练使用 CE loss。

### 3.1 E4: Baseline CE

| 阶段 | R@5 | R@10 | R@20 | N@5 | N@10 | N@20 | MRR@5 | MRR@10 | MRR@20 |
|------|------|------|------|------|------|------|------|------|------|
| Val | 0.0530 | 0.0800 | 0.1158 | 0.0356 | 0.0443 | 0.0533 | 0.0300 | 0.0335 | 0.0360 |
| Test | 0.0364 | 0.0578 | 0.0875 | 0.0236 | 0.0304 | 0.0379 | 0.0194 | 0.0222 | 0.0242 |

> Test 显著低于 Val（R@20 差距 0.0283），原因同上。

### 3.2 Ablation: RQ-VAE vs RQ-KMeans

| Variant | Test R@5 | Test R@10 | Test R@20 | Test N@20 |
|-----------|-----------|-----------|-----------|----------|
| TrainSK+InferSK (E1) | 0.0347 | 0.0564 | 0.0829 | 0.0365 |
| RQ-KMeans (E4) | **0.0364** | **0.0578** | **0.0875** | **0.0379** |
| Δ | +4.9% | +2.5% | +5.5% | +3.8% |

> RQ-KMeans 在所有指标上一致优于 RQ-VAE。

### 3.3 Ablation: First-Diff Loss

| TIGER Loss | Test R@5 | Test R@10 | Test R@20 | Test N@20 |
|------------|-----------|-----------|-----------|----------|
| CE (E4) | **0.0364** | **0.0578** | **0.0875** | **0.0379** |
| CE + FD (w=0.1) | 0.0339 | 0.0529 | 0.0811 | 0.0355 |

> FD loss 在 RQ-KMeans 上同样全面下降。结合 RQ-VAE 结果和 first-diff 位置分析（94.3% 分叉在 L1），FD loss 与 CE 在 L1 高度冗余，缺乏独立信号。

### 3.4 Ablation: L4 替代 Extra Token

| λ | Test R@5 | Test R@10 | Test R@20 | Test N@20 |
|----|-----------|-----------|-----------|----------|
| — (E4, Extra Token) | 0.0364 | 0.0578 | 0.0875 | 0.0379 |
| 10 | 0.0372 | **0.0590** | 0.0887 | 0.0386 |
| **1** | **0.0374** | 0.0575 | **0.0890** | **0.0390** |

> L4 (λ=1) 取得全局最优 R@20=0.0890, N@20=0.0390。相比 Extra Token：R@20 +1.7%, N@20 +2.9%。λ=1 优于 λ=10。

### 3.5 Ablation: L4 + First-Diff Loss

| TIGER Loss | L4 | Test R@5 | Test R@10 | Test R@20 | Test N@20 |
|------------|:--:|-----------|-----------|-----------|----------|
| CE | — | 0.0364 | 0.0578 | 0.0875 | 0.0379 |
| CE | ✓ (λ=10) | 0.0372 | **0.0590** | 0.0887 | 0.0386 |
| CE + FD | ✓ (λ=10) | 0.0362 | 0.0577 | 0.0870 | 0.0378 |

> FD loss 在 L4 上也没有收益。

## 4. 关键 Ablation 总结

### 4.1 SID 算法选择

| 对比 | Δ R@20 | 结论 |
|------|--------|------|
| RQ-VAE → RQ-KMeans | +0.0046 (+5.5%) | K-Means 逐层训练优于 VAE+Sinkhorn |
| Extra Token → L4 (λ=1, KMeans) | +0.0015 (+1.7%) | 可学习 L4 有边际收益 |
| Sinkhorn 导出 vs 不导出 | +0.0003 (≈0) | Sinkhorn 导出非必要，Extra Token 足够 |

### 4.2 Loss 函数

| 对比 | Δ R@20 | 结论 |
|------|--------|------|
| CE → CE + FD (RQ-VAE) | −0.0047 (−5.7%) | FD 有害 |
| CE → CE + FD (RQ-KMeans) | −0.0064 (−7.3%) | FD 有害 |
| CE → CE + Collab (RQ-VAE) | −0.0009 (−1.1%) | Collab 无显著影响 |

> FD loss 在 6 组对比中全部降低性能。根本原因：first-diff 在 94.3% 的样本中发生在 L1，而 L1 的 CE loss 已经足够强，FD 的 pairwise logistic 梯度与 CE 方向一致但不提供新信息。

### 4.3 最优配置

**全局最优：RQ-KMeans + L4 (λ=1) + CE loss**

| Metric | Value |
|--------|-------|
| Test R@5 | **0.0374** |
| Test R@10 | 0.0575 |
| Test R@20 | **0.0890** |
| Test N@20 | **0.0390** |

## 5. 路线演进

```
E1 TrainSK+InferSK (CE)         R@20=0.0829
 ├─ +Collab                     R@20=0.0820  (−0.9%)  → 放弃
 ├─ +FD (w=0.1)                 R@20=0.0782  (−5.7%)  → 放弃
 ├─ E2 去掉 InferSK              R@20=0.0826  (−0.3%)  → InferSK 非必要
 ├─ E3 去掉 TrainSK              R@20=0.0795  (−4.1%)  → TrainSK 必要
 ├─ +L4 (λ=10)                  R@20=0.0806  (−2.8%)  → 对 VAE 无效
 │
E4 RQ-KMeans (CE)               R@20=0.0875  (+5.5%)
 ├─ +FD (w=0.1)                 R@20=0.0811  (−7.3%)  → 再次确认 FD 无效
 ├─ +L4 (λ=10)                  R@20=0.0887  (+1.4%)  → 有效
 ├─ +L4 (λ=1)                   R@20=0.0890  (+1.7%)  → 最优
 └─ +L4 (λ=10) + FD             R@20=0.0870  (−0.6%)  → FD 在 L4 上也无益
```

**最终方向**：放弃单路优化，转向 TIGER + Content-Sim 多路融合（RRF 融合后 R@20=0.1125，+34.9% vs 最优单路）。
